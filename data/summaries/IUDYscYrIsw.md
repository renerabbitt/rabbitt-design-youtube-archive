# Summary

This Template Tuesday session focuses on precise movement, resizing, snapping, and placement workflows in Chief Architect. The video moves through walls, doors, windows, backsplashes, cabinets, island layouts, snap indicators, rotation points, offsets, and extended cabinet styles, with several side lessons on project management and Pro Plan toolbars.

The session opens with a quick Windows PowerToys tip for screen docking and then answers live questions about importing Rabbitt Design toolbars into Chief Architect X18 and switching project layouts after starting a plan. The layout-switching workflow uses project management copies, document folders, and the Reference Plan Layout tool to reassociate a layout with the correct plan file.

The core precision section starts with walls. It explains why most wall precision should come from dimensions after drawing rooms, then shows how to use CAD lines, polar coordinates, and the Tab/Enter coordinate dialog to create exact reference geometry. It also covers wall edit handles, resizing walls about the inner surface versus main layer outside, reversing wall layers, understanding interior/exterior wall sides, and resizing multiple exterior walls while preserving measured interior dimensions.

The next section covers doors and windows. It demonstrates concentric resize, setting jump distances for 2-inch door increments, using the `C` or comma key for temporary concentric resizing, changing door heights in 3D, setting matching window head heights, and changing room/default plate heights from an exterior room selection.

The video then moves into 3D resize workflows for backsplashes and cabinets. It shows how to resize a backsplash to surrounding objects by typing `0`, why drawing one clean backsplash rectangle can be easier than fixing automatically created breaks, and how to use the cabinet dimension edit subtool to choose between moving an object and moving/resizing an edge.

The cabinet section is the largest part of the session. It covers precise cabinet placement in plan and 3D, copy/paste placement instead of repeated click placement, moving cabinets exact distances from surrounding objects, reflecting cabinets, using multiple copy for island layout, applying Rabbitt Design style-palette tools by marquee selection, suppressing automatic fillers, using modular 3-inch cabinet increments, and centering ranges or cabinet groups between two points.

The later section explains Chief Architect snap indicators and how midpoint, center, endpoint, primary, and secondary snap colors help verify precise placement. It also demonstrates placing points as rotate/resize centers, rotating objects around a placed point, using multiple copy with rotation to create array-like patterns, and using copy/paste resize handles to create precise offsets.

The session ends with a live question about extended cabinet styles. It builds an Extended Style Painter style palette for base, wall, and full-height cabinets, applies it to a cabinet near a wall, turns on bumping/pushing for precise movement, and shows how extended style fields can report in a cabinet schedule. The closing note discusses Pro Plan X18 beta status, missing pony wall library objects, layer-based fill style updates, and plans to continue the precision movement topic in a future Template Tuesday.
