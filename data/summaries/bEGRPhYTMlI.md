# Summary

This Template Tuesday session explores Chief Architect X18's new Project Information system and how it can become more than basic client/designer metadata. The video demonstrates adding custom project information fields, inserting those values into text and note macros, and using the system as a foundation for title blocks, project information sheets, automatic annotations, specification blocks, and future Pro Plan template systems.

The first half focuses on creating and using project information fields. A custom `Scope of Work` field is added under the Project heading, filled with a project-specific value, and inserted into text and note objects from Chief Architect's macro dropdown. The video explains the macro syntax, why exact names matter, and how these values can be reused anywhere text macros are supported.

The video then moves into a title block and project information workflow. It shows how Rabbitt Design's Pro Plan uses a separate plan file to drive title block data, logo, stamp, design load criteria, and spec writing across multiple layouts. The new Project Information system can replace older custom parsing systems that relied on colon-delimited values and custom fonts, although custom scripting still matters when blank fields need to disappear automatically or when bold headings and normal values must be mixed in a generated text block.

The session also demonstrates using AI to quickly generate macro text from screenshots, discusses the limits of Chief's Project Information dialog such as no word wrapping and no sort order, and explains how project information could support reusable design annotations such as tile pattern notes, starter tile notes, and library objects that pull in project-specific values.

The second half branches into Chief Architect X18 beta features. It gives a deep demonstration of layer-based fill styles, including wall layers, roof planes, framing members, foundation walls, poche fills, wall hatching, and active view display control. It also shows X18 cladding and roof material improvements, custom low-poly cladding materials, brick depth variation, grass regions, window treatment tricks, stretch-plane symbols for beams/corbels, and a closing discussion about polyline solids, soffits, and why architectural/parametric objects are often preferable to free solids.
