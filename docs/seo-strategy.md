# SEO Strategy

The video archive should do two jobs:

1. Help people find the right Rabbitt Design video quickly.
2. Send search traffic and authority back to `rabbittdesign.net`.

Those are related, but they are not the same job.

## Recommended Direction

Use this repo as the source of truth and content generator. Publish the public-facing SEO value through Rabbitt Design whenever possible.

Best path:

- Store transcripts, summaries, chapters, subchapters, topics, and keywords in this repo.
- Generate a searchable static archive for GitHub Pages or a custom subdomain.
- Generate SEO-focused content pages that can live on Squarespace.
- Link every GitHub-hosted video/search result back to Rabbitt Design services, products, training, and related topic pages.

## Why GitHub Pages Alone Is Not Enough

GitHub Pages is good for:

- Fast prototyping.
- Free static hosting.
- A searchable index app.
- Sharing an archive with technical users.

GitHub Pages is weaker for:

- Building authority for the main Rabbitt Design domain.
- Converting visitors into clients, members, or product buyers.
- Managing calls to action and business pages in one place.

If search engines rank a GitHub Pages URL instead of a Rabbitt Design URL, the traffic may not build as much value for the main website.

## Best SEO Structure

The strongest version is a topic-based content hub on Rabbitt Design:

```text
rabbittdesign.net/videos
rabbittdesign.net/videos/toolbars
rabbittdesign.net/videos/toolbars/toolbar-configuration-transfer
rabbittdesign.net/videos/foundations
rabbittdesign.net/videos/foundations/foundation-tips-and-tricks
```

Each page should include:

- A human-written topic intro.
- Embedded related videos.
- Chapter links.
- Short transcript excerpts.
- A cleaned summary.
- Related topic links.
- Calls to action for training, templates, VIP, Discord, or services.

## GitHub Pages Role

The GitHub site should be the interactive search tool.

It can live at:

```text
https://<github-user>.github.io/<repo-name>/
```

or a branded subdomain:

```text
videos.rabbittdesign.net
```

A branded subdomain is better than a raw GitHub URL because it keeps the experience under the Rabbitt Design brand.

## Squarespace Role

Squarespace should own the SEO landing pages.

There are three practical options:

1. Manual publish: generate page drafts from this repo, then paste them into Squarespace.
2. Embed search: embed the GitHub search app on a Squarespace page for user experience.
3. Hybrid: publish topic pages on Squarespace and link to the GitHub search tool for advanced filtering.

Important: embedding the GitHub app in an iframe helps users, but the transcript/search content inside the iframe usually does not give Squarespace the same SEO value as native Squarespace page text.

## Content Flow

1. Import video metadata.
2. Add transcript.
3. Generate summary, chapters, subchapters, keywords, and related topics.
4. Build the GitHub search index.
5. Generate Squarespace-ready topic/page copy.
6. Publish or paste the generated copy into Squarespace.
7. Add backlinks from the GitHub tool to the matching Rabbitt Design pages.

## Backlink Strategy

Every video page and result should point users toward Rabbitt Design:

- Main website: `https://www.rabbittdesign.net/`
- Video library: `https://www.rabbittdesign.net/videos`
- Chief Architect search page: `https://www.rabbittdesign.net/chiefsearch`
- Relevant products or VIP pages when a video mentions them.

The GitHub tool should never be a dead end. It should act like a discovery layer that sends people deeper into the Rabbitt Design site.

## Search Term Strategy

Each video should produce multiple search targets:

- Exact video title.
- Clean title variant.
- Problem statement.
- Tool or feature names.
- Chapter names.
- Subchapter category.
- Common beginner wording.
- Advanced user wording.

Example for the toolbar video:

- Chief Architect toolbar tricks
- copy toolbar configuration Chief Architect
- Chief Architect custom toolbar icons
- Chief Architect `.toolbar` file
- Chief Architect managed resources backup
- TreeSize Chief Architect temp directory
- reset Chief Architect toolbars

These phrases can become search index keywords, Squarespace headings, and related links.
